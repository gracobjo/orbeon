Significado de las etiquetas

            

                

                    Auto
                    Se puede aplicar al XML sin revisión: el campo y el cambio están definidos en el catálogo del formulario.
                

                

                    Revisar
                    No se aplica solo: hay que comprobarlo (p. ej. altas de controles nuevos copiando del XML objetivo).
                

                

                    alta
                    Confianza alta — Correspondencia directa entre la anotación del PDF y el campo XML (ID o texto del catálogo).
                

                

                    media
                    Confianza media — Correspondencia inferida (texto parcial, proximidad en el PDF o regla genérica). Verifique el campo afectado.
